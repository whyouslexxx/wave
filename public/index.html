Настройка VK API

Для поиска ВК нужен Сервисный ключ доступа (Service Token).

Как получить ключ:

  1. Перейдите на VK Developers
  2. Создайте приложение типа «Standalone»
  3. Скопируйте «Сервисный ключ доступа»
  4. Вставьте в config.json → поле VK_SERVICE_TOKEN и перезапустите сервер

Если сервер на чужом хостинге — обратитесь к его владельцу.
